Vice City sunset multi-panel GTA 6-style cover art maker: turn your photo and a caption into a striking multi-panel poster, exported as a PNG to share. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Load a photo, arrange the panels, edit the caption, and export a PNG (1080x1080, 1080x1350, 1920x1080).
